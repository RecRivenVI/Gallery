# 验证与历史记录

本目录把“当前验证结果”和“历史记录”与产品说明、架构决策和未来计划分开。这里的记录不会定义产品行为，也不会仅凭过去一次通过就把当前工作树标记为可发布。

| 文档 | 类型 | 当前用途 |
| --- | --- | --- |
| [当前验证记录](evidence-log.md) | 验证记录 | 记录本次文档重写前的源码静态核验范围、结果和限制 |
| [大规模测试历史](scale-test-archive.md) | 历史材料 | 保存旧 1M/10M 合成测试的最小可用摘要及证据缺口 |
| [Git 历史重写记录](history-rewrite-log.md) | 过程历史 | 记录当前 Git 日志中可确认的历史重写事件 |

## 记录规则

新的验证记录至少写明日期、代码或工作树基线、环境、命令或核验方法、结果、未覆盖范围以及原始产物位置。原始日志、数据库、媒体、secret、Cookie、私密 metadata 和机器绝对路径不提交到仓库；仓库内只保留去敏摘要和可复现入口。

历史材料必须明确说明证据是否仍存在。没有可定位原始产物、不能在当前代码上复现或只来自旧叙述的结果，不得作为当前 Gate 的通过依据。
