# Web 设计系统代码

本目录实现用户端和管理端共享的视觉与交互基础。长期设计说明见 [`docs/design/web/`](../../../docs/design/web/README.md)；这里仅记录代码边界和使用规则。

## 文件

| 文件                                | 职责                                           |
| ----------------------------------- | ---------------------------------------------- |
| `tokens.css`                        | 主题、密度、颜色、间距、排版、焦点和动效 token |
| `reset.css`                         | 双入口共享的基础重置                           |
| `primitives.tsx` / `primitives.css` | React Aria 基础组件与样式                      |
| `icons.tsx`                         | 共享线性图标                                   |
| `motion.ts`                         | 具有稳定业务键的有界连续布局动效               |
| `index.ts`                          | 公共导出面                                     |

## 使用规则

- 页面从本目录导入 primitive，不复制按钮、字段、对话框、状态或通知的私有实现。
- 业务样式引用语义 token，不直接建立第二套主题、状态色或时序。
- `gallery` 与 `manage` 是 surface；theme 与 density 分别管理，不能互相替代。
- capability 只控制明显不可用入口，服务端响应仍是授权权威。
- 空、加载、无权限、网络失败和 Source 不可用必须区分。
- 列表顺序、过滤、分页和快照来自服务端，前端不私自重排。
- 纯图标控件提供可访问名称；危险操作使用明确文案和确认。
- `prefers-reduced-motion` 下不创建逻辑动画；视觉副本必须 `inert`、`aria-hidden` 并及时清理。

新增 primitive 时同时补充组件/样式测试，并检查两个 surface、四种主题、两种密度、键盘和窄屏行为。
