# ADR-12：采用仓库规范与暂停基线

## 状态

已接受。用户于 2026-10-21 决定。

## 背景

Gallery 暂缓开发，等待 Gallery-Legacy 完工后再决定代码迁入；旧目录、CI、阶段日志和已入库 bundle 与共用规范不一致。

## 决策

- 根规则原样采用仓库规范 1.0.0，项目特有不变量作为 X- 补充。
- 契约在 api，版本元数据在 internal/version；产品版本从 Git 注入。旧 ADR-11 的结构/文档/验证流程由本记录取代，其原文保留。
- 文档按七类、场景按 validations 组织；实验、原始结果与构建产物外置，删除 CI 和自建检查器。
- 保留现有业务、Schema 和有效测试，不把本轮规范整理扩为功能修复。

## 后果

干净检出须先构建前端再编译 Go。常规验证直接调用 Go/npm 原生工具；本机工具路径不入库。既有 UI/架构问题列为技术债，不能据目录整理宣称产品已可用。
