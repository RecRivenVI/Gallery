# ADR-0008：可替换桌面壳

- 状态：Accepted
- 日期：2026-07-16

## 上下文

Windows 用户未来可能需要托盘、窗口和自启动体验，但把数据库、规则或授权放入桌面壳会让服务端无法独立运行，也会锁定单一 UI 框架。

## 决策

- 桌面壳不是核心组件，`galleryd` 必须可独立启动和提供全部 API。
- 壳只能负责进程发现/启动、WebView、窗口、托盘、深链和 OS 生命周期集成。
- 壳不得直连 SQLite、复制授权、实现规则或绕过 HTTP API。
- 壳与服务通过 runtime descriptor 和正式 API 协作。
- 当前正式产品树不选择或交付桌面壳；Wails 只保留为隔离实验输入。

## 理由

薄壳保持后端可测试、可替换和可由浏览器/CLI 使用，也避免在 Windows RC 核心门禁前承担额外框架与签名表面。

## 影响

- Web/PWA 与便携浏览器形态可以先交付，不等待桌面框架。
- 未来选择 Wails、WebView2 或其它技术时无需迁移业务状态。
- 壳的崩溃和升级不能损坏 AppDirs 或改变服务协议。

## 重新审议

只有 Windows x64 后端与 Web 候选稳定，且明确需要原生系统集成时，才新增 ADR 选择具体壳技术。
