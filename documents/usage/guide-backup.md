# 备份与恢复

你可以备份账户、授权、收藏、规则和绑定等用户事实。备份不包含原媒体或可重建目录；网页目前只能查看备份清单，不能上传或下载文件。

1. 打开管理端“验证和诊断”，创建备份并等待任务完成。
2. 查看备份清单，确认大小、校验值和兼容状态。
3. 恢复前先执行“验证恢复”；失败时不要继续登记恢复。
4. 登记恢复后，请运行服务的人关闭并重新启动服务；恢复只在启动时应用。
5. 重新登录，确认收藏等重要事实。恢复会丢弃备份之后的修改，所有客户端都需要重新认证。

损坏、不兼容或校验失败的备份不能替换当前数据。不要手工复制正在使用的数据库或删除恢复状态来绕过失败；保留错误信息并寻求协助。
