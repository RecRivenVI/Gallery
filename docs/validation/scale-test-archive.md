# 大规模合成测试历史

## 文档状态

类型：历史材料  
原记录时间：2026-07-21 至 2026-07-23  
本次复核时间：2026-08-01

本文件保留旧 1M/10M Catalog 合成测试的最小背景。当前工作树中没有旧记录所引用的原始 JSON 报告、测试数据库或 `tools/stage4` 工具，因此下列数字不能独立复核，也不能作为当前性能 Gate 或正确性 Gate 的通过依据。

## 当时的目的和方法

旧记录描述了一组确定性合成 Work、Media 和 Overlay 数据。工具直接调用当时的 Catalog Store 建立候选 revision、应用 Overlay、校验并发布，再通过真实 `galleryd` 的 HTTP 接口执行正确性、游标和性能探针。数据不包含真实媒体内容。

## 旧记录保留的结果

以下是原记录的陈述，不是本次复测结果：

| 场景 | 原记录结论 |
| --- | --- |
| 1,000,000 Work | 构建并发布完成；构建总耗时记录为 506,750 ms |
| 1M 正确性 | 39 项断言、0 失败 |
| 1M cursor | 6 项断言、0 失败 |
| 1M 性能 | 宽中文搜索和部分结构化过滤在高并发下出现几十秒至两分钟级延迟；“请求无失败”不代表性能达标 |
| 10,000,000 Work | 构建在约 120 分钟上限被中止，没有 manifest、publication 或后续查询结果 |

原记录据此把百万级以上语料定位为昂贵的诊断场景，而不是每次发布的常规门禁。当前门禁定义不再从本历史文档继承，应以 [`docs/development/testing-and-release-gates.md`](../development/testing-and-release-gates.md) 和现有 testlab 实现为准。

## 当前仍有价值的结论

- 性能报告必须同时保留延迟分位数、失败、超时和未执行组合；断言成功不能替代预算判定。
- 长跑应原子保存进度和环境指纹，恢复运行必须拒绝语料、publication、工具版本或环境漂移。
- 未完成候选不能描述为已发布 Catalog，强制终止也不能描述为产品正确性失败。
- 大规模数据构建、查询并发和 Source I/O 是不同测试维度，不能互相替代。

## 证据缺口

- 原始 manifest、报告、SQLite 文件、WAL、日志和当时工具源码均不在当前仓库。
- 原记录中的硬件、存储和完整逐组合延迟没有在本次任务中重新核验。
- 当前 Catalog schema、查询实现和 testlab 已继续演进，旧数值不能预测当前性能。

若未来需要重新建立大规模基线，应使用当前 `tools/testlab`、独立 AppDirs、固定语料 manifest 和新的去敏报告；不要把本历史摘要复制为新结果。
