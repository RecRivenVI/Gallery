# Web 设计

Gallery 的 Web 客户端由同一 React/TypeScript 工程提供两个入口：用户端位于 `/`，管理端位于 `/manage/`。两者共享会话、错误处理、实时恢复、设计 token 和基础组件，但服务于不同任务。

## 已实现边界

- 用户端和管理端都使用共享 `AppShell`、响应式导航和 `ToastProvider`。
- 用户端构建为 PWA；管理端是独立入口，不进入用户端离线壳。
- PWA 只缓存应用外壳和静态资源，不缓存 API、WebSocket 或媒体响应。
- 页面数据以 HTTP 快照为基础；WebSocket 用于提示变化，序列缺口或重连后重新获取已挂载资源。
- 权限控制使用服务端 capability；隐藏操作不是安全边界。
- 桌面与窄屏共用同一信息架构。窄屏导航以模态抽屉呈现，关闭后把焦点返还给触发元素。

## 不在本文档中定义

- 服务端授权、publication、规则或媒体读取语义；
- 原生桌面桥接、托盘、进程启停或直接配置文件编辑；
- 尚未形成实现与验收方式的移动端专有交互；
- 精确页码跳转。当前查询采用 keyset cursor，响应总数可能为下限或省略。
