# Gank 规则夹具说明

`bounded-subdir-v1.json` 覆盖常用 metadata 字段、媒体分类、显式封面以及 `1.*` 的较高优先级封面候选。它没有实现两类条件隐藏：

| 条件 | 当前原因 |
| --- | --- |
| 同目录存在压缩包时隐藏编号预览图 | 规则求值上下文只包含当前文件，没有同目录兄弟文件清单；当前 primitive/CEL 输入无法表达 |
| metadata 中出现外链时隐藏编号预览图 | metadata 与当前路径可供 CEL 使用，但 converter 不知道真实字段是字符串还是数组；猜测类型可能让整个 Source 求值失败 |

这两项属于明确未转换语义。第一项需要正式扩展规则输入或 primitive；第二项需要在获准的有界只读调查中只确认字段形态，再建立类型安全的合成测试。不得在测试夹具或 provider 代码中写来源专用特例来绕过规则系统。

带无法表达条件的封面候选不会被转换成无条件候选。这样会回退到显式封面或第一张可见媒体，避免看似成功但实际选错封面。
