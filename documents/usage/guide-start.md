# 开始使用画廊

你可以浏览已经登记和扫描的媒体来源。项目尚未正式发行；当前暂停功能开发，界面仍有使用限制。

1. 打开服务显示的本机地址，点击“开始配对”。
2. 进入管理端“扫描与任务”，创建资料库并登记只读来源。
3. 在“规则”中创建或导入规则，发布后为来源建立绑定，再发起扫描。
4. 返回用户端浏览作品。若提示“内容未确认”，在作品页创建“确认内容”任务，完成后再查看原媒体。
5. 你可以收藏或记录进度；这些用户事实不会被重扫覆盖。

登记前请确认名称和路径，目前不能事后改名、停用或删除来源。规则配置和来源确认仍较复杂；未完成用户验收。网页不能替你启动或重启后台服务；需要协助时向运行服务的人确认。
