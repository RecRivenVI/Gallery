# Web 动效系统

动效用于表达操作反馈、状态变化和对象连续性，不承担装饰性入场，也不替代文字状态。

## 时序层级

共享 token 定义四档语义时序：

| 层级 | 当前时长 | 用途 |
| --- | ---: | --- |
| direct | `0ms` | 拖动、缩放等直接操纵 |
| feedback | `110ms` | 按钮、菜单和局部反馈 |
| state | `180ms` | 状态显现、离场和小范围切换 |
| structure | `280ms` | 有身份对象的位置变化和结构调整 |

曲线同样由语义 token 提供。业务组件引用 token，不复制硬编码时长。`prefers-reduced-motion` 下 CSS 时长归零，逻辑层也不创建 WAAPI 动画。

## 有身份列表

`useKeyedLayoutMotion` 只用于具有稳定业务键的列表：

- 同一键保留时，从旧位置过渡到新位置；
- 新键在最终位置轻量显现；
- 消失键只留下短暂视觉副本，副本设为 `aria-hidden` 和 `inert`，不接收焦点或点击；
- 新更新可以中断旧动画，最后一次数据状态获胜；
- 只记录视口附近的有限对象，默认动画预算为 72 项，避免成本随长列表无界增长；
- 浏览器不支持所需能力、对象超出预算或用户要求减弱动画时，直接提交最终状态。

真实 DOM 始终拥有数据、语义和交互。视觉副本不得带重复 ID、可聚焦后代或业务事件。

## 用户端

- 同一资源范围的查询更新可以保留旧网格视觉，但旧网格不可交互且不进入无障碍树。
- 媒体在解码完成后于固定槽位内显现，不用动画掩盖加载失败。
- 查看器的拖动、缩放和其他指针直接操纵使用 `direct` 层级，不追加惯性缓动来延迟输入结果。
- 路由和滚动恢复在布局阶段完成，不能依赖长动画把错误位置隐藏起来。

## 管理端

管理端只使用按钮、菜单、开关、浮层和局部状态的短反馈。轮询、任务状态和表格数据原位更新；同一状态行不因每次刷新反复入场。危险操作的严重性由文案、确认和状态色表达，不用抖动或夸张动画。

## 清理要求

动画完成、取消、组件卸载或数据再次变化时必须清理 Animation 对象、定时器和视觉副本。已结束动画不得长期以 `fill` 状态挂在节点上。自动化验证应至少覆盖中断、减弱动画、离场副本语义和卸载清理。
