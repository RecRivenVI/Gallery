# 用户端体验

用户端面向媒体浏览与查看，入口位于 `/`。它读取服务端已发布的 Catalog 和用户 Overlay，不直接读取或修改 Source。

## 信息架构

当前路由包括：

| 路由 | 任务 |
| --- | --- |
| `/` | 用户端首页和可用入口 |
| `/browse` | 搜索、筛选、排序与连续加载作品 |
| `/sources/:sourceId` | 按来源浏览 |
| `/creators` | 浏览作者 |
| `/creators/:creatorId` | 查看作者及其作品 |
| `/works/:workId` | 查看作品、媒体和 Overlay |
| `/works/:workId/view/:mediaId` | 路由化媒体查看器 |
| `/files` | 浏览已授权文件根 |
| `/files/:rootId` | 浏览指定文件根 |

桌面侧栏提供主要页面、来源和获授权文件根；窄屏以模态抽屉呈现同一导航。路由是可分享和可恢复的界面状态，媒体查看器不使用只存在于组件内的临时地址。

## 浏览与检索

- 查询由服务端执行，筛选、排序和 cursor 必须与当前 publication 及授权范围一致。
- 结果总数可能是精确值、下限或省略；界面不推导不存在的精确页数。
- 同一来源、Library 或 Creator 范围内切换搜索、筛选和排序时，可在新快照到达前保留旧视觉；旧内容必须 `inert` 且从无障碍树隐藏。
- 跨资源范围切换时不复用旧结果，避免把上一范围的数据表现为当前事实。
- 连续加载按固定作品块管理，只挂载视口附近的卡片；返回历史路由时恢复先前滚动位置。
- 新查询会取消旧请求，旧响应或旧结构化错误不得覆盖当前路由和搜索状态。

## 作品与媒体

- 作品页展示 publication 绑定的作品快照、媒体列表和服务端允许的 Overlay 操作。
- Overlay 包括收藏、进度和自定义封面等用户数据；写入冲突由服务端版本语义处理。
- 媒体只在实际解码完成后显现，固定槽位避免解码造成布局跳动。
- 查看器支持直接拖动和缩放；指针直接操纵期间不增加缓动。
- 媒体暂时忙碌或可重试读取失败时，界面保留当前上下文并按结构化错误恢复；未确认或不可读媒体不能伪装成成功。

## 文件根

文件页只展示服务端配置并授权的文件根。客户端不接收任意本机绝对路径作为浏览入口，也不把 Source 目录自动等同于文件根。

## 状态与恢复

- 首次加载、空结果、权限不足、可重试失败和终态失败分别呈现。
- WebSocket 只提示状态变化；断线、序列缺口或服务恢复后重新获取 HTTP 快照。
- 离线期间不耗尽重连预算；上线后刷新 bootstrap、连接和已挂载资源。
- PWA 不缓存 API 或媒体，因此离线壳不能被描述为离线媒体库。
