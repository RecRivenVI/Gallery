# Feedback Cleanroom Lab

类型：历史实验模块  
状态：不属于正式构建、测试或运行时

本独立 Go module 保存第二轮反馈型净室探针，包括只读结构调查、规则、身份、Catalog 提交、搜索、排序、契约、平台和壳层实验。部分命令可以接收真实根路径，因此默认不得运行。

## 安全边界

- 真实 Source 必须得到当前任务的明确授权并保持只读；
- 输出只保留脱敏代号、计数、类型、耗时和折叠摘要；
- 不保存 metadata 原文、媒体内容、绝对媒体路径、完整 URL、Cookie 或 Token；
- 结果、数据库、缓存和复制夹具写入独立临时目录，不写入 Source；
- 旧实验结论不自动适用于当前正式实现。

正式验证已由 [`tools/testlab/`](../../../tools/testlab/README.md) 承担。若确需复核本目录，先读取具体 `cmd/*` 源码和帮助，再单独记录基线、命令、输出位置和限制；不要引用旧 README 的命令或历史结论作为当前证据。
